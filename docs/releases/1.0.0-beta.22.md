# Actua 1.0.0-beta.22

Beta 22 completes full Actual Budget tag support, fixes transfer transactions not applying matching rules, and makes budget progress bars goal-aware.

## Added

- Full Actual Budget tag support: consistently colored tags across every transaction list, `#` autocomplete with inline tag creation in transaction notes, a native **Manage Tags** screen (create, edit, delete, color, hidden state), and tap-a-tag transaction discovery/filtering — all backed by Actual's canonical tag dataset and refreshed after sync
- A README hero image and a mobile-friendly screenshot gallery

## Changed

- Budget category progress bars now fill toward an active budget-automation goal instead of always reading as spend-down, so a long-term funding goal shows real progress before anything is spent

## Fixed

- Fixed colored transaction-note tags rendering inconsistently across transaction lists (main Transactions tab, account lists, detail screens), including tag metadata schema handling and cache invalidation after sync
- Fixed transfer transactions not applying matching Actual rules — selecting a destination account now triggers rule evaluation and applies supported actions like Notes and Cleared

## Compatibility and safety

- Tag rendering remains display-only and never mutates transaction notes or synchronized tag metadata; unknown or malformed tag metadata falls back to normal text
- Categories without an active goal keep their existing spend-down progress behavior unchanged
- Transfer rule matching uses Actual's canonical transfer-payee representation rather than a raw account id, and linked transfer creation/persistence is unaffected
