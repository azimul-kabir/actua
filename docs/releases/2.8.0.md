# Actua 2.8.0

Actua 2.8.0 replaces the F-Droid build with Direct Full, so the main GitHub APK now has receipt scanning and shows every
Supporter extra. Everyone can preview all the app icons, accent colors, Catppuccin themes and widget styles, with the
locked ones marked "Supporter". Receipt photos now travel with encrypted WebDAV backups, a Quick Settings tile adds a
transaction in one tap, and Manage Tags can act on several tags at once. Large budgets save and edit faster, and several
screens no longer pause. Budgeting itself always stays free.

## Before you update

- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.
- The Google Play version and the GitHub APKs are signed with different keys, so a GitHub APK cannot be installed over
  the Play version, or the reverse. To move between them, back up your budget (an archive, WebDAV or Google Drive),
  uninstall, install the other build and restore. The two GitHub APKs update each other.

## Notes

- **Supporter extras are cosmetic and optional.** They can be unlocked in the Google Play version for now. The GitHub
  APKs show every extra locked until website purchases open, and budgeting stays free for everyone. Supporter status
  in the Google Play version is checked with Google Play and cached on the device; it is never sent anywhere else.
- **Website purchases are not open.** Direct builds cannot activate a purchase yet, and nothing in this release takes
  a website payment. The Terms of Service, Privacy Policy and Refund Policy already describe how they will work.
- **Receipt scanning is in every build.** The Google Play version and both GitHub APKs read a receipt on your phone
  with Google ML Kit, which may send technical diagnostics to Google but never your receipt or budget data.
- **Internal work in this release** has no visible effect: the navigation state extraction (#1681 to #1687), faster
  budget opening and Merkle updates (#1688, #1702), and test and benchmark repairs.
