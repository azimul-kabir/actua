# Actua 2.8.0

Actua 2.8.0 replaces the F-Droid build with Direct Full, so the main GitHub APK now has receipt scanning and shows every
Supporter extra. Everyone can preview all the app icons, accent colors, Catppuccin themes and widget styles, with the
locked ones marked "Supporter". Receipt photos now travel with encrypted WebDAV backups, a Quick Settings tile adds a
transaction in one tap, and Manage Tags can act on several tags at once. Large budgets save and edit faster, and several
screens no longer pause.

## Before you update

- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a new
  version with a real budget.
- The Google Play version and the GitHub APKs are signed with different keys, so a GitHub APK cannot be installed over
  the Play version, or the reverse. To move between them, back up your budget (an archive, WebDAV or Google Drive),
  uninstall, install the other build and restore. See Notes.

## Notes

- **Direct Full replaces the F-Droid build.** `Actua-v2.8.0.apk` on GitHub is now the full app, with on-device receipt
  scanning and every Supporter extra shown locked. Website purchases are not open, so nothing in this release takes a
  payment and its Support screen says "coming soon". `Actua-v2.8.0-full.apk` is the Google Play build.
- **Play and GitHub installs are signed differently.** Google signs the Play version with its own key, while both GitHub
  APKs use Actua's release key. The two GitHub APKs update each other, but a GitHub APK cannot replace the Play version,
  or the reverse. To switch, back up your budget, uninstall, install the other build and restore.
- **Supporter extras are cosmetic and optional.** They can be unlocked in the Google Play version for now, and budgeting
  stays free for everyone. Supporter status in the Google Play version is checked with Google Play and cached on the
  device; it is never sent anywhere else.
- **Receipt scanning is in every build.** The Google Play version and both GitHub APKs read a receipt on your phone with
  Google ML Kit, which may send technical diagnostics to Google but never your receipt or budget data.
