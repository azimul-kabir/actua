# Actua 2.5.3

Actua 2.5.3 fixes Scan receipt failing with a NullPointerException in the Google Play version, and makes three WebDAV
backup errors say what to change.

## Before you update

- Receipt scanning is in the Google Play version and the `-full` APK only; this release does not change that.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.

## Fixed

- Fixed Scan receipt failing with a NullPointerException in the Google Play build
  ([#1506](https://github.com/azimul-kabir/actua/pull/1506))
- Fixed WebDAV backup errors pointing at the wrong problem: a rename refused behind a reverse proxy, an HTTPS address on
  a plain HTTP port, and a 405 at the server root now explain what to change
  ([#1504](https://github.com/azimul-kabir/actua/pull/1504))

## Notes

- A WebDAV server behind a reverse proxy that changes the port or scheme refuses the rename Actua uses to finish an
  upload. Connect to the server's own address and port instead. See "Synology and reverse proxies" in
  [WebDAV backups](../WEBDAV_BACKUPS.md).
