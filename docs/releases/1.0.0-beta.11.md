# Actua 1.0.0-beta.11

This beta focuses on Android home-screen widgets and a safer, faster device-testing workflow.

## Highlights

- **Responsive Material You widgets.** Budget Snapshot and Quick Transaction now support a compact **2x2** layout plus wider **3x1 / 4x1** forms when resized on the launcher.
- **Smaller balance/category widgets.** Account Balances and Favourite Categories now fit practical **2x2** layouts with tighter spacing and improved category progress bars.
- **Fixed Expense shortcut icon.** The launcher long-press **Add expense** action now uses a clear minus icon so it is visually distinct from Add income on Pixel Launcher.
- **Actua Test builds.** A new manual **Build Test APK** GitHub Actions workflow can build a branch, tag, or commit without publishing a release. The resulting app is named **Actua Test** and uses `com.azimulkabir.actua.test`, so it can be installed beside normal Actua with separate Android app data.
- Widget resize changes are applied immediately for Budget Snapshot and Quick Transaction while preserving existing dynamic color, dark mode, privacy formatting, currency/decimal settings, deep links, and refresh behavior.

## Testing development branches

For unreleased work, open **GitHub → Actions → Build Test APK → Run workflow** and enter the branch or commit to test. Download the generated `Actua-Test-...` artifact after the run completes. This does not create a tag, GitHub release, Obtainium update, or Discord release notification.

## Upgrade notes

Actua 1.0.0-beta.11 uses the same production application ID and persistent release signing identity as recent beta releases, so it should install as a normal in-place update over beta.10.

> [!CAUTION]
> Actua remains beta software and can write synchronized changes back to an Actual budget. Create an independent backup of an important Actual budget before testing, and confirm important changes have synchronized before uninstalling or resetting Actua.
