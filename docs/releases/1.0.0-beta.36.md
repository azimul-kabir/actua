# Actua 1.0.0-beta.36

Beta 36 adds bank sync setup and management, category status dots, and fixes Home's favorite-card navigation and back behavior, a certificate trust prompt, an early-schedule-posting display bug, and Home's This Month calculation.

## Added

- New Bank Sync management page (Accounts "+" → Set up bank sync, and Manage → Bank Sync): configure SimpleFIN (setup token) or GoCardless (Secret ID/Key), discover provider accounts, and link them to an existing or newly created account. Accounts now fetches all linked bank accounts via pull-to-refresh, and a single linked account's register can also be refreshed individually. Pluggy.ai is surfaced as not yet supported
- Status dots on category rows and cards sharing the same color logic as the category progress bar, with per-status color overrides (and reset to defaults) and a show/hide switch, all in Settings → Budget → Category status colors

## Fixed

- Favorite category cards on Home now open that category's Budget details directly instead of only opening the Budget overview
- Favorite account cards on Home now open that account's transactions directly instead of only opening the Accounts overview
- Repeated back presses/gestures now collapse to the Home tab before exiting the app, instead of stopping on Budget
- Home's This Month card no longer counts transfers between on-budget accounts as income and spending; it uses the same category-aware cash-flow calculation as Accounts
- The certificate trust prompt now inspects and pins whichever server URL (primary or fallback) actually failed with an untrusted certificate, instead of always the primary
- Post Transaction Today no longer leaves a just-completed recurring schedule occurrence looking due after it advances the schedule to its next date; the Bills calendar keeps showing that occurrence as paid

## Compatibility and safety

- Bank sync setup, linking and unlinking write through the existing CRDT mutation and sync pipeline; pull-to-refresh only downloads and imports transactions for accounts already linked, the same as the SimpleFIN download already shipped in beta 35
- Category status dots and their color/visibility preferences are local presentation settings; they read the existing budget progress calculation and do not affect Budget filters or synced data
- The certificate trust fix only changes which URL is inspected/pinned during an already-failed connection attempt; hostname/SAN verification and fail-closed behavior are unchanged
- The schedule fix only widens which linked payment can mark the immediately-preceding occurrence paid on the calendar display; it does not change which transactions are created or how `next_date` advances
- The favorite-account navigation and back-stack changes only affect which screen a tap or back press lands on; they reuse the existing transaction-list and navigation destinations rather than adding new ones
