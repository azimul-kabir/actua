# Actua 1.0.0-beta.41

Beta 41 fixes six report-widget calculation and rendering bugs: Age of Money,
Crossover, Budget Analysis, Spending and Sankey now match Actual's PWA/Web
output more closely, Monte Carlo runs a real stochastic simulation instead of
a deterministic projection, and the in-line `#tag` pill in transaction notes
is now rounded.

## Fixed

- The Age of Money report widget now counts a transfer to an account outside the widget's account filter as an expense, matching the PWA, instead of dropping it whenever the counterpart account is on-budget ([#536](https://github.com/azimul-kabir/actua/pull/536))
- The Crossover report widget now uses the PWA's historical-balance CAGR for its default return, Hampel/median/mean expense projection, and last-historical-balance seeding instead of a safe-withdrawal-rate fallback and plain expense average ([#535](https://github.com/azimul-kabir/actua/pull/535))
- The Budget Analysis report widget now respects its category/category-group filters and shows the budget engine's carried-over balance instead of an unfiltered, non-rolling total ([#534](https://github.com/azimul-kabir/actua/pull/534))
- The Spending report widget no longer excludes all transfers; it now matches Actual's PWA/Web filtering, which only drops the leg on an off-budget account ([#533](https://github.com/azimul-kabir/actua/pull/533))
- The Sankey report widget now breaks income down by source and shows its date range, matching Actual's PWA/Web output ([#528](https://github.com/azimul-kabir/actua/pull/528))
- The Monte Carlo report widget now runs a real success-rate retirement simulation instead of showing a deterministic dollar projection ([#527](https://github.com/azimul-kabir/actua/pull/527))
- The in-line `#tag` pill in a transaction's notes field is now rounded, matching the saved tag chip style instead of a flat rectangle ([#513](https://github.com/azimul-kabir/actua/pull/513))

## Compatibility and safety

- All six report-widget fixes are calculation/rendering changes inside the shared `ReportAggregator`/`CoreReportEngine` layer; no synced or stored transaction, budget or schedule data is read differently, only how existing data is aggregated and displayed
- The tag pill fix is presentation-only and does not change stored note text
