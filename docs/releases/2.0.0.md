# Actua 2.0.0

Actua 2.0.0 lets you budget entirely on your device. You can create or import a standalone budget
without a server, back up to your own Google Drive with encryption, build custom reports, import more
bank statement formats, and organise accounts into groups. Actua is now licensed under the GNU
General Public License v3.0.

## Before you update

- **Actua is now GPL v3.** Earlier releases were MIT-licensed; the credited upstream MIT code keeps
  its notices (see `NOTICE.md`).
- **Standalone budgets stay when you disconnect from a server.** Only server budgets are cleaned up.
- As always, let Actua finish syncing before you update, and keep an independent backup from
  Actual before using a new version with a real budget.

## Compatibility and safety

- Standalone budgets use Actual's database format and message log, and are exported and imported
  as Actual `.zip` archives. They stay on your device unless you upload them to a server.
- Google Drive backups request only the `drive.file` scope and are encrypted on the device with
  authenticated encryption (key derived from your backup password) before upload, so Google cannot read
  them. See `PRIVACY.md`.
- Account groups, split transfer lines, rule actions and imports write through Actual's CRDT message
  path, so they stay compatible with Actual.
- No database schema, Merkle or sync-protocol changes.
