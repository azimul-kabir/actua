# Actua 1.0.0-beta.35

Beta 35 refines the new Home experience, makes Transactions and budget changes feel more responsive, and fixes schedule and OpenID recovery paths.

## Added

- Refreshed Home's dashboard presentation with clearer hierarchy, dependable floating-action-button clearance, and This Month activity scoped to the selected budget month
- Added pull-to-refresh on Transactions
- Added a Reverse control for an unsaved transfer draft
- Added the category's current available balance to the saved-transaction confirmation cue
- Added `make debug-apk` for a local debug APK build

## Fixed

- Manually posting a recurring schedule on its due date now advances it to the next occurrence
- Returning from an unsuccessful OpenID browser flow no longer leaves Connection & Data loading indefinitely
- Switching budgets now shows a loader until the selected budget is ready instead of presenting stale content as the new budget
- Tag suggestions containing underscores stay on one line

## Compatibility and safety

- Pull-to-refresh and the budget-switch loader only refresh displayed local/synchronized state; they do not create CRDT messages or change financial data.
- Transfer reversal applies only to an unsaved draft. Saving still uses Actua's normal atomic paired-transfer CRDT writer.
- Manual recurring-schedule posting advances the existing schedule through its established CRDT next-date mutation path.
