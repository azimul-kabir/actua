# Actua 2.4.0

Actua 2.4.0 brings Actua up to date with Actual Budget 26.11. Rule formulas now work in everyday amounts like
Actual's, reports that split by tag show up correctly, schedules pick the same next date and post on the same day
as Actual, and a few safeguards keep a download or a sign-out from leaving something behind. It also adds renaming
a budget, making a one-time schedule from a future transaction, funding a goal from To Budget, hiding reconciled
transactions in All Accounts, and recovery flows for a budget whose server sync was reset or whose encryption
password changed.

## Actual 26.11 parity

Actua's compatibility target is now Actual Budget v26.11.0. Its sync protocol, encryption and database
migrations are unchanged since 26.9 apart from one internal table, and the 60 migration ids in a new Actua budget
match 26.11 exactly. This release also closes the user-visible differences found when 26.11 was compared with
Actua. What was reviewed, what changed and what is not ported is in
[docs/ACTUAL_26_11_COMPATIBILITY.md](../ACTUAL_26_11_COMPATIBILITY.md).

## Before you update

- **Rule formulas changed meaning, as they did in Actual 26.11.** A formula now reads `amount`, `balance`,
  `parent_amount` and `BALANCE_OF(...)` as everyday amounts (10.00, not 1000) and writes the result back the same
  way. A formula written to work around the old cents behavior, such as `=amount / 100`, now divides twice. The same
  rule behaves the same in Actual and Actua again.
- **Disconnect now contacts your server** to end the session, then forgets the token on the phone as before. If
  the server cannot be reached or is older than 26.11, Disconnect still completes and the session simply expires on
  its own.
- A budget's database gains an internal `messages_pending` table when it is opened. Nothing else in it is rewritten.
- Reports that split by tag, the zero-based forecast axis and hiding reconciled transactions in All Accounts read
  settings that were made in Actual. Actua does not yet offer Tag in its own report builder or a zero-based axis
  option in its own widget settings.
- Funding a goal from To Budget moves money between your envelopes. It is capped at what is left in To Budget and
  is written like any other budget change.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.

## Added

### Budget and goals

- Fund goal from To Budget in a category's actions: budgets the rest of an underfunded goal, up to what is left in
  To Budget. It is not offered in a tracking budget, for income categories or for long-term goals
  ([#1433](https://github.com/azimul-kabir/actua/pull/1433))
- Add categories to the income group in Manage Categories ([#1398](https://github.com/azimul-kabir/actua/pull/1398))

### Accounts and schedules

- Hide reconciled transactions in the All Accounts list, kept in sync with Actual through its
  `hide-reconciled-all` setting ([#1432](https://github.com/azimul-kabir/actua/pull/1432))
- Make one-time schedule in the editor of a future-dated transaction, which turns it into a schedule that posts it
  on its date ([#1403](https://github.com/azimul-kabir/actua/pull/1403))

### Reports

- Reports that split by tag, made in Actual, show their tag groups and honour the tags chosen for them
  ([#1427](https://github.com/azimul-kabir/actua/pull/1427))
- Balance Forecast widgets set to a zero-based y-axis in Actual draw their axis from zero
  ([#1431](https://github.com/azimul-kabir/actua/pull/1431))
- Export a report widget's data table to CSV from its full-screen view ([#1402](https://github.com/azimul-kabir/actua/pull/1402))

### Server and budget files

- Rename a budget from Connection settings, including its name on the Actual server ([#1404](https://github.com/azimul-kabir/actua/pull/1404))
- Back up and re-download a budget whose server sync was reset ([#1400](https://github.com/azimul-kabir/actua/pull/1400))
- Recover a budget whose encryption password was changed in Actual by entering the new password and re-downloading
  it ([#1401](https://github.com/azimul-kabir/actua/pull/1401))

### Currencies

- Norwegian krone, Tanzanian shilling and South African rand in the currency list, and the Swiss franc now
  shows as CHF ([#1430](https://github.com/azimul-kabir/actua/pull/1430))

## Changed

- Disconnect also ends the session on the Actual server ([#1428](https://github.com/azimul-kabir/actua/pull/1428))
- Sync keeps changes for tables or columns Actua does not know yet, so a newer Actual can still read them
  ([#1420](https://github.com/azimul-kabir/actua/pull/1420))

## Fixed

- A downloaded server budget could replace a different budget on the phone that shared its internal id, including
  its unsynced changes. It now always installs as its own budget ([#1419](https://github.com/azimul-kabir/actua/pull/1419))
- Rule formulas read and return everyday amounts instead of cents, matching Actual 26.11
  ([#1423](https://github.com/azimul-kabir/actua/pull/1423))
- `#template schedule` underfunded a category when a schedule repeats every N days or weeks and N spans more than a
  month ([#1424](https://github.com/azimul-kabir/actua/pull/1424))
- A new or edited weekly schedule skipped a weekend date that moves to the next weekday
  ([#1425](https://github.com/azimul-kabir/actua/pull/1425))
- A scheduled transaction that posts automatically was not posted until the next day when its schedule was created
  or edited after that day's run ([#1426](https://github.com/azimul-kabir/actua/pull/1426))
- Learning a payee's category created a duplicate rule when a "payee is one of" rule already set it
  ([#1429](https://github.com/azimul-kabir/actua/pull/1429))

## Compatibility and safety

- **Database:** Actua's new budgets and upgraded budgets carry all 60 of Actual 26.11's migration ids. 2.4.0 adds
  one internal table, `messages_pending` (migration `1788468782000`, introduced by Actual 26.10), created with
  `CREATE TABLE IF NOT EXISTS`. It works on the oldest supported Android SQLite. No other schema, Merkle tree,
  encryption or sync-protocol changes.
- **Sync:** changes for a table, column or value format Actua cannot apply yet are kept in `messages_pending`
  (newest per cell) and applied the next time the budget is opened after an update. Changes Actua writes itself are
  never held back. A budget Actua uploads therefore no longer loses those cells for a newer Actual.
- **Downloads:** a download is never installed under an id from inside the downloaded file unless that id is free
  or already belongs to the same server file. Re-downloading over a local budget requires that budget to be the
  copy of the same server file, and a server reply for a different file is refused.
- **Schedules and rules:** posting and next-date changes follow Actual 26.11 and add no new stored fields. The
  formula change affects how stored formulas are evaluated, not how they are stored.
- **Sign-out:** the token is sent only to your own Actual server, with the saved custom headers and certificate
  trust, and is never logged.
- **Reports and display:** tag reports, the forecast axis, the currency list and the All Accounts switch only change
  what Actua shows or read settings that already exist in your budget. Hiding reconciled transactions in All
  Accounts writes one synced setting.
- **Testing:** this release was verified by Actua's automated tests, lint and the Android 9, 15 and 16 emulator runs,
  plus the Actual 26.9.0 comparison checks. It was not run against a live Actual 26.11 server or checked on a
  physical device before release; see `RELEASE_SMOKE_TEST.md` for the device checks.
