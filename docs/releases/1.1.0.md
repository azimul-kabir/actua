# Actua 1.1.0

Actua's first release after 1.0.0 adds manual drag-to-reorder for accounts,
displays accounts grouped by Actual's experimental account groups, and adds
an uncategorized-transactions banner to the Budget screen alongside the
existing overspent-categories one. It also fixes a bank-sync duplicate-import
bug, improves the category picker and add-transaction flow, and stops
off-budget transactions with no category from being mislabeled as
"Uncategorized".

## Added

- Added manual drag-to-reorder for accounts on the Accounts screen ([#603](https://github.com/azimul-kabir/actua/pull/603))
- Accounts synced into Actual's experimental account groups are now displayed grouped on the Accounts screen ([#609](https://github.com/azimul-kabir/actua/pull/609))
- Added an uncategorized-transactions banner to the Budget screen, alongside the overspent-categories one, both now controlled by a single "Show warnings" toggle ([#612](https://github.com/azimul-kabir/actua/pull/612))

## Fixed

- Bank sync now reconciles with an existing manually entered transaction instead of importing it as a duplicate ([#604](https://github.com/azimul-kabir/actua/pull/604))
- Show category balances while picking a category, and preselect the account when adding a transaction from an Account Detail screen ([#608](https://github.com/azimul-kabir/actua/pull/608))
- Off-budget-account transactions with no category are no longer shown or filtered as "Uncategorized" ([#611](https://github.com/azimul-kabir/actua/pull/611))

## Compatibility and safety

- Account reordering writes through the existing CRDT-backed account writer and sync path; no new schema or protocol change
- Account grouping is read-only display: Actua never creates, renames, reorders, or reassigns Actual's `account_groups`, and unmodified budgets keep the existing flat account list
- The uncategorized-transactions banner and off-budget uncategorized fix are read-side filtering/display changes only; no synced or stored transaction data is read or written differently
- No database schema, sync protocol or migration changes
