# Actua 2.3.0

Actua 2.3.0 adds an optional app lock and a setting that hides Actua in the recents screen, CSV export of
transactions, and opening bank statement files straight from other apps. It also adds Pluggy.ai and Akahu bank
sync, a field-mapping editor for bank sync, a Month note entry in the Budget menu, and weekly, biweekly and
semi-monthly loan payment schedules.

## Before you update

- **The app lock is off by default** and needs a screen lock (PIN, pattern, password or biometrics) set up on
  your device. In this release it protects the main app only: widget settings screens, the Tasker plug-in
  screen and widget contents are not covered yet, and the recents preview is taken before the lock engages. Turn
  on **Hide app contents in recents** to keep balances out of the recents screen. See
  [docs/APP_LOCK.md](../APP_LOCK.md).
- **Hide app contents in recents is off by default** and also blocks screenshots and screen recording in Actua.
- **CSV exports are plain text.** They contain your transaction details unencrypted and are saved wherever you
  choose; keep them as private as the budget itself.
- **Pluggy.ai, Akahu and Enable Banking follow Actual's server API and are covered by tests, but have not been
  run against live providers.** They need an Actual server with the provider set up.
- Enable Banking is now a regular bank sync provider. The **Settings > Experimental > Enable Banking** switch is
  gone.
- Actua now declares Android's `USE_BIOMETRIC` and `USE_FINGERPRINT` permissions for the app lock. They are
  normal permissions and show no prompt.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.

## Added

### App lock and screen privacy

- An optional app lock in Settings > Privacy that asks for a fingerprint, face or your device PIN, pattern or
  password before Actua shows any budget data, with a relock timeout of Immediately, 1, 5 or 15 minutes. Turning
  it on or off requires authenticating, a restarted app always asks again, and a rotation does not relock. It uses
  Android's own prompt, so Actua never sees your biometric data ([#1388](https://github.com/azimul-kabir/actua/pull/1388))
- A Settings > Privacy switch that hides Actua's contents in the recents screen and blocks screenshots and screen
  recording ([#1385](https://github.com/azimul-kabir/actua/pull/1385))

### Import and export

- Open bank statement files shared from another app (CSV, XLSX, PDF, OFX, QFX, QIF or CAMT.053) directly in the
  transaction importer, from the share sheet or "Open with"; nothing is imported until you confirm the review ([#1386](https://github.com/azimul-kabir/actua/pull/1386))
- Export to CSV in an account's register menu, in Actual's account-export layout with splits, exact amounts and
  cleared or reconciled status ([#1387](https://github.com/azimul-kabir/actua/pull/1387))
- Export the transactions a filter or search is showing, and every Global Search match (not just the loaded
  pages), to CSV ([#1389](https://github.com/azimul-kabir/actua/pull/1389))

### Bank sync

- Pluggy.ai and Akahu bank sync, Enable Banking as a regular provider, and per-account sync settings in Manage
  Bank Sync ([#1331](https://github.com/azimul-kabir/actua/pull/1331))
- Per-budget Pluggy.ai credentials and an editor for each linked account's bank sync field mappings ([#1332](https://github.com/azimul-kabir/actua/pull/1332))

### Budget and loans

- A Month note entry in the Budget menu to view and edit the selected month's note ([#1330](https://github.com/azimul-kabir/actua/pull/1330))
- Biweekly, semi-monthly and weekly payment schedules for loan tracking ([#1326](https://github.com/azimul-kabir/actua/pull/1326))

## Changed

- The Budget dropdown menu has row icons and shows the active budget name on the switch row ([#1328](https://github.com/azimul-kabir/actua/pull/1328))

## Compatibility and safety

- No database schema, Merkle tree, encryption or sync-protocol changes.
- The app lock and the recents setting are device-local. They change what this device shows and nothing else:
  the budget database, your Actual server and the way credentials are kept in the Android Keystore are unchanged.
  Background sync, scheduled posting and reminders keep running while the app is locked.
- CSV export is read-only; it writes only to the location you pick and never changes the budget.
- Sharing a file to Actua reads it through the temporary access Android grants for that file. A file type Actua
  doesn't recognise is refused with a message instead of being guessed as CSV.
- Per-account bank sync settings and field mappings use Actual's own synced preference ids, as Actual does.
- Loan schedules add optional `paymentFrequency` and `secondPaymentDay` keys to a loan's existing stored
  settings, which Actuali ignores. Existing monthly loans are unchanged.
