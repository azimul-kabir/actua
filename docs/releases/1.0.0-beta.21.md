# Actua 1.0.0-beta.21

Beta 21 focuses on safer and more complete Actual Budget compatibility, plus a few UI refinements.

## Added

- Full **Balance Cap** automation editing with daily, weekly, and monthly cadence options
- Weekly Balance Cap start-date selection
- Support for retaining or releasing balances above a cap to match Actual's `hold` behavior
- Actual Budget tag colours in transaction notes, including case-sensitive matching and safe fallbacks

## Changed

- Standalone Balance Cap automations are now treated as a distinct supported automation rather than a read-only refill variant
- Balance Cap planning now preserves Actual's carryover and excess-release semantics without introducing refill funding
- Replaced the oversized project README with a shorter user-focused overview, feature list, screenshots, install links, credits, and community links

## Fixed

- Fixed sync-progress layout on **Connection & Data** so the loading indicator and text remain correctly aligned and spaced on narrow displays
- Fixed sync banner padding and indicator placement regressions

## Compatibility and safety

- Advanced Balance Cap definitions round-trip without being silently rewritten
- Unknown, malformed, or unsupported tag colour metadata falls back to normal note rendering
- Tombstoned tag definitions are ignored, while active hidden tags retain their metadata
- Tag rendering is display-only and never modifies transaction notes or synchronized tag metadata
