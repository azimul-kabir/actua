# Actua 1.0.0-beta.14

This beta adds OpenID Connect authentication for Actual servers and includes two UI stability fixes merged after beta.13.

## Highlights

- **OpenID Connect / OIDC support.** Actua can now sign in to Actual servers configured for OpenID authentication, including OIDC-only setups.
- **Browser-based authentication.** Actua asks the Actual server to start the OpenID flow, opens the provider login in the browser, and receives the resulting Actual session token through a temporary localhost callback.
- **Password compatibility preserved.** Password login now explicitly requests Actual's password method, so mixed password + OpenID server configurations can continue to work where permitted by the server.
- **No provider secrets in Actua.** Identity-provider client IDs and client secrets stay configured on the Actual server. Actua receives only the resulting Actual session token.
- **Safer callback handling.** The temporary callback listener is bound to localhost rather than exposed to the local network.
- **Stable blank amount fields.** Focusing an empty transaction or split amount no longer causes the field layout to shift when the custom cursor appears or blinks.
- **Consistent compact navigation.** Icon-only bottom navigation now keeps the same container background through the Android system bottom inset.

## OpenID setup note

OIDC is configured on the **Actual Budget server**, not inside Actua. After OpenID is enabled in Actual and an identity provider is configured there, open **More → Connection & Data** in Actua, enter the Actual server URL, and choose **Sign in with OpenID**. Provider authentication completes in the browser and returns to Actua automatically.

## Upgrade notes

Actua 1.0.0-beta.14 uses the same production application ID and persistent release signing identity as recent beta releases, so it should install as a normal in-place update over beta.13. Obtainium users who enabled prereleases should receive the update after publication.

> [!CAUTION]
> Actua remains beta software and can write synchronized changes back to an
> Actual budget. Create an independent backup of an important Actual budget
> before testing, and confirm important changes have synchronized before
> uninstalling or resetting Actua.
