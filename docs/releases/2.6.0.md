# Actua 2.6.0

Actua 2.6.0 stops a budget that fails to open from being deleted, makes backup restores and budget downloads safer,
and adds a way to recover a budget that can't be opened. It also remembers your "Mark as cleared" choice, fixes
dashboard cards, goal templates and the plain-HTTP check, and closes a few ways a budget could lose recent changes.

## Before you update

- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.
- If you connect to your server over plain `http://` using a public hostname that starts with "fc" or "fd", Actua now
  asks for HTTPS instead. See Notes.

## Added

- Added a notice when a budget can’t be opened, with options to try again, re-download it, restore a backup or delete
  it ([#1523](https://github.com/azimul-kabir/actua/pull/1523))
- Added remembering the “Mark as cleared” choice for each budget on Import and Review captured, including Import from
  capture notifications ([#1532](https://github.com/azimul-kabir/actua/pull/1532))

## Fixed

- Fixed dashboard cards and reports that exclude a category by name leaving out transactions without a category
  ([#1533](https://github.com/azimul-kabir/actua/pull/1533))
- Fixed the year-to-date dashboard cards leaving out transactions whose payee is an account but that aren’t linked
  transfers ([#1531](https://github.com/azimul-kabir/actua/pull/1531))
- Fixed a failed budget download or import being able to delete the budget it replaced, or lose its latest changes
  ([#1530](https://github.com/azimul-kabir/actua/pull/1530))
- Fixed plain HTTP being allowed to public server addresses starting with “fc” or “fd”, which could send your password
  unencrypted ([#1527](https://github.com/azimul-kabir/actua/pull/1527))
- Fixed goal templates losing a cent, for example a 19.99 template budgeting 19.98
  ([#1525](https://github.com/azimul-kabir/actua/pull/1525))
- Fixed restoring a backup while a sync or scheduled backup was running, which could corrupt the budget
  ([#1524](https://github.com/azimul-kabir/actua/pull/1524))
- Fixed server-backed budgets, with their unsynced changes and local backups, being deleted when they failed to open
  ([#1522](https://github.com/azimul-kabir/actua/pull/1522))

## Notes

- **A budget that can't be opened is kept.** Actua no longer deletes it. It stays on your device with its backups and any
  unsynced changes, and a banner offers to try again, re-download it from your server, restore one of its backups, or
  delete it. Deleting and re-downloading always ask first, and re-download backs up the local copy before replacing it.
- **Restore and download are safer.** A restore pauses sync and waits for any backup in progress. Restores, downloads
  and imports swap the budget files in by renaming, so an interrupted operation leaves either the old budget or the new
  one.
- **Plain HTTP is limited to local and private addresses.** `http://` is accepted for `localhost`, `*.local`,
  `*.localhost`, private IPv4 addresses and private IPv6 addresses (such as `[fd00::1]`). A public hostname that merely
  starts with "fc" or "fd" was wrongly treated as private before. If you used one, switch to `https://`.
- **Dashboard cards follow Actual's filters.** Cards and reports that exclude a category by name, for example "does not
  contain Starting Balances", now count transactions that have no category, as Actual does. Their totals can rise to
  match Actual. Linked transfers are still excluded.
