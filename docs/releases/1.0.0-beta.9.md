# Actua 1.0.0-beta.9

Beta.9 focuses on distribution compatibility for F-Droid-style source and binary verification.

## Changed

- Removed opaque dependency metadata from APK and app bundle signing blocks so F-Droid's binary scanner can inspect release artifacts cleanly.
- Prepared version 26 store metadata for F-Droid-compatible repositories.

## Upgrade

- Continues using Actua's persistent release signing key and can upgrade recent beta installations in place.
- No budgeting, transaction, synchronization, or local-data behavior changed in this release.
