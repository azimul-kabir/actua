# Actua 1.4.0

Actua 1.4.0 redesigns Add transaction as a single page and carries its card
layout across the whole app: Home, Budget, Accounts, Reports, schedules, rules,
settings and sheets now share the same hero amounts, rounded cards and icons.
It adds Tasker and other automation apps as a transaction source, lets you
post, skip or complete an upcoming scheduled transaction by tapping it, and
opens a schedule's rule from the schedule editor. Transfers now behave like
Actual when deleted, edited, categorized or bulk-edited, missed scheduled
transactions stay visible, and bank sync stops re-importing re-sent rows and
explains timeouts.

## Before you update

- **Add transaction is one page.** There are no longer separate Expense,
  Income and Transfer modes. The amount's sign sets expense or income (use the
  sign toggle next to the amount), and choosing an account as the payee makes a
  transfer, where the same toggle reverses the transfer. Launcher shortcuts for
  Expense, Income and Transfer still open the form preset accordingly.
- **Tasker integration is off by default.** Nothing changes until you turn on
  *Accept transactions from Tasker* on the import screen. Broadcasts only join
  the import review queue; nothing is written to the budget until you import
  it. See [Tasker and other automation apps](https://github.com/azimul-kabir/actua/blob/main/docs/TRANSACTION_IMPORTS.md#tasker-and-other-automation-apps).
- As always, let Actua finish syncing before you update, and keep an
  independent backup from Actual before using a new version with a real budget.

## Compatibility and safety

- Deleting a transfer, or saving it as an expense or income, tombstones the other leg (or unlinks it when it is a split child) in the same CRDT batch, as Actual's `removeTransfer` does ([#754](https://github.com/azimul-kabir/actua/pull/754))
- Transfer edits copy only the fields Actual's `updateTransfer` copies, so the other leg keeps its own cleared state and date, and schedule links are written to both legs ([#755](https://github.com/azimul-kabir/actua/pull/755))
- On/off-budget transfers store their category on the on-budget leg only, as Actual does ([#756](https://github.com/azimul-kabir/actua/pull/756)); the full transaction, transfer and split audit, including the remaining filed divergences, is in [TRANSACTIONS_PARITY.md](https://github.com/azimul-kabir/actua/blob/main/docs/TRANSACTIONS_PARITY.md) ([#753](https://github.com/azimul-kabir/actua/pull/753))
- Posting, posting today, skipping and completing an upcoming schedule go through the existing schedule CRDT write path ([#740](https://github.com/azimul-kabir/actua/pull/740))
- Bank sync fuzzy matching now also considers rows already imported under a different provider id, as Actual does for bank-sync accounts; downloads use Actual's 5-minute read timeout and store `timed-out`/`account-missing`/`failed` statuses like Actual ([#799](https://github.com/azimul-kabir/actua/pull/799), [#800](https://github.com/azimul-kabir/actua/pull/800))
- The Tasker receiver is exported but ignores every broadcast unless the integration is on and the per-install token matches; accepted items only enter the bounded local review queue ([#802](https://github.com/azimul-kabir/actua/pull/802))
- The redesign is presentation-only; no stored budget data is written differently
- No database schema, sync protocol, encryption or Merkle changes
