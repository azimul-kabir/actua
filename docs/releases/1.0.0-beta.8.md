# Actua 1.0.0-beta.8

Beta.8 focuses on safer server disconnection and consistent transaction currency display.

## Changed

- Manual **Disconnect & Reset** now performs a final synchronization of downloaded server budgets before clearing local server-bound data.
- If the final sync fails, Actua stops the reset and requires an explicit force-disconnect choice instead of silently discarding local state.
- Disconnect cleanup preserves device-level preferences and the local demo budget while cancelling stale budget reminder work and clearing budget-bound state.

## Fixed

- Add/Edit Transaction amount fields now follow the currency selected in **More → Display → Currency** instead of always showing the BDT `৳` symbol.
- Split amount fields, **Use remaining**, and split remainder text now use the same selected currency.
- Added regression coverage for BDT, USD, EUR, GBP, symbol-only formatting, and no-currency display.

## Upgrade

This release uses Actua's persistent release signing key and can be installed directly over recent beta builds. As always, keep synchronized server data and tested backups when using a beta with an important budget.
