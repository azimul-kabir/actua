# Actua 1.0.0-beta.23

Beta 23 adds a read-only Upcoming Schedules home-screen widget and fixes the transaction notes `#` tag autocomplete that beta.22 shipped but never actually wired up.

## Added

- A read-only **Upcoming Schedules** home-screen widget: unpaid scheduled transactions with overdue items shown first, relative due labels ("Today", "Tomorrow", "In N days", "N days overdue"), a per-instance configurable 7/14/30-day period, a compact layout for smaller widget sizes, and a tap-through deep link to Scheduled Transactions
- A tappable `#` trailing icon in the transaction Notes field, matching Actual's mobile UI, so a tag can be started without typing `#`

## Fixed

- Fixed transaction notes `#` tag autocomplete never appearing in Add/Edit Transaction — typing `#` in the main Notes field or a split note now shows matching-tag suggestions and an inline "Create #tag" option, consistent with the behavior `docs/tags.md` already documented

## Compatibility and safety

- The Upcoming Schedules widget is strictly read-only: no post, skip, complete, or other financial mutation is reachable from it
- The widget respects hide-balances, currency, and decimal-place display preferences, and refreshes automatically after sync and schedule mutations through the same shared refresh path every other widget uses

## Manual verification still needed

The Upcoming Schedules widget's on-device behavior — placing it on a home screen, resizing it through the compact breakpoint, tapping it, and confirming empty/no-budget states — has not yet been manually verified on a device. See the `RELEASE_SMOKE_TEST.md` checklist items covering this widget before promoting this build further.
