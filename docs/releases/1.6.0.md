# Actua 1.6.0

Actua 1.6.0 makes rules and budget templates behave like Actual: rules now run on
file, notification and bank-sync imports and on the other side of new transfers,
see earlier rules' changes, and apply template, formula and split actions, while
budget templates budget, round and set category goals the way Actual does. It also
adds a budget switcher at the top of Manage and a one-tap "cover the full
overspending" option when moving money.

## Before you update

- **Rules now run in more places.** Transactions imported from files, SMS or bank
  notifications, bank sync, and the other leg of a new transfer now go through your
  rules, as in Actual. If you relied on imports arriving uncategorized, review the
  rules that match them before importing.
- **Rules behave more like Actual.** Each rule now sees the changes earlier rules
  made, `contains`/`matches` conditions on payee, category and account compare ids
  (as Actual does) rather than names, and template, formula and split actions
  created in Actual are now applied instead of being skipped. These actions are still
  edited in Actual; Actua's rule editor doesn't create them.
- **Budget templates can give different amounts.** Simple, average, percentage of
  last month, refill with a weekly or daily cap, repeating save-by-date and schedule
  templates now match Actual, amounts are rounded to whole units when the budget
  hides decimals, and applying templates sets each category's goal, so underfunded
  and overfunded colors match Actual. Preview before applying, as always.
- **"Color budgeted amounts" is now "Color balances".** The status color now sits
  behind the category's Balance instead of its Budgeted amount; your on/off choice is
  kept.
- As always, let Actua finish syncing before you update, and keep an
  independent backup from Actual before using a new version with a real budget.

## Added

- Switch between downloaded budgets from a row at the top of Manage ([#844](https://github.com/azimul-kabir/actua/pull/844))
- Cover an overspent category's full amount in one tap from the Move Money sheet ([#841](https://github.com/azimul-kabir/actua/pull/841))

## Fixed

### Rules

- Rules now apply Actual-compatible templates, formulas and split actions, saving generated splits atomically ([#888](https://github.com/azimul-kabir/actua/pull/888))
- Bank sync runs rules before matching, so matched transactions get rule categories and renamed payees no longer leave the bank's name behind ([#875](https://github.com/azimul-kabir/actua/pull/875))
- Rules now run on the other side of a new transfer, like Actual ([#874](https://github.com/azimul-kabir/actua/pull/874))
- Rules now run on transactions imported from files and notifications, like Actual ([#873](https://github.com/azimul-kabir/actua/pull/873))
- Rules treat transfers like Actual in category-none and transfer conditions ([#872](https://github.com/azimul-kabir/actua/pull/872))
- Rule contains/matches conditions on payee, category and account now compare ids like Actual instead of names ([#871](https://github.com/azimul-kabir/actua/pull/871))
- Rules now see changes made by earlier rules, so chained rules such as rename-then-categorize work like Actual ([#867](https://github.com/azimul-kabir/actua/pull/867))

### Budget templates

- Set budgets to zero now also clears income category budgets in tracking budgets, like Actual ([#885](https://github.com/azimul-kabir/actua/pull/885))
- Budget templates round to whole amounts when the budget hides decimals, like Actual ([#884](https://github.com/azimul-kabir/actua/pull/884))
- Average templates now count refunds and round like Actual ([#883](https://github.com/azimul-kabir/actua/pull/883))
- Percentage templates of last month's income now budget like Actual instead of nothing ([#882](https://github.com/azimul-kabir/actua/pull/882))
- Refill templates with a weekly or daily cap now top up to the month's full cap like Actual ([#881](https://github.com/azimul-kabir/actua/pull/881))
- Schedule templates for bills due in later months now save toward them like Actual's sinking fund ([#880](https://github.com/azimul-kabir/actua/pull/880))
- Repeating save-by-date templates whose date has passed now roll forward like Actual instead of budgeting the whole target at once ([#879](https://github.com/azimul-kabir/actua/pull/879))
- Budget templates now set category goals like Actual, so underfunded and overfunded colors match across clients ([#878](https://github.com/azimul-kabir/actua/pull/878))
- Applying budget templates now picks up `#template` notes written in other Actual clients ([#877](https://github.com/azimul-kabir/actua/pull/877))
- Simple budget templates such as `#template 50` and `#template up to 100` now budget like Actual ([#876](https://github.com/azimul-kabir/actua/pull/876))

### Budget and widgets

- Budget table amounts now shrink to fit narrow screens and large font sizes instead of clipping decimals ([#887](https://github.com/azimul-kabir/actua/pull/887))
- The Upcoming Schedules widget now scrolls through every schedule in its period instead of showing only four ([#870](https://github.com/azimul-kabir/actua/pull/870))
- Status colors now tint the Balance instead of the Budgeted amount on Budget rows ([#843](https://github.com/azimul-kabir/actua/pull/843))

## Compatibility and safety

- Rules are checked against Actual's own `runRules` (`@actual-app/api` 26.9.0) by a synthetic fixture of 149 transactions and 91 rules; every case matches, with no known divergences ([#848](https://github.com/azimul-kabir/actua/pull/848), [docs/RULES_PARITY.md](https://github.com/azimul-kabir/actua/blob/main/docs/RULES_PARITY.md))
- Budget templates are checked against Actual's engine on two identical synthetic budgets across apply, overwrite and month-end cleanup, comparing budgeted amounts, `goal` and `long_goal`; no cells differ ([#847](https://github.com/azimul-kabir/actua/pull/847), [#849](https://github.com/azimul-kabir/actua/pull/849), [docs/BUDGET_AUTOMATION_PARITY.md](https://github.com/azimul-kabir/actua/blob/main/docs/BUDGET_AUTOMATION_PARITY.md))
- A two-client check makes the same 17 transaction edits through Actual and Actua against one `actual-server` 26.9.0 and found identical synced rows; Actua still writes some explicit null/zero cells Actual leaves out, which is intentional ([#845](https://github.com/azimul-kabir/actua/pull/845), [#846](https://github.com/azimul-kabir/actua/pull/846))
- Rule-generated splits write the parent and its children in one atomic batch through the existing transaction writer; formula results are rounded to integer cents and an evaluation error leaves the field unchanged ([#888](https://github.com/azimul-kabir/actua/pull/888))
- Template goals are written to the category's `goal`/`long_goal` cells in the same atomic budget batch as the amounts ([#878](https://github.com/azimul-kabir/actua/pull/878))
- Status colors and table-amount sizing are presentation-only; stored amounts are unchanged ([#843](https://github.com/azimul-kabir/actua/pull/843), [#887](https://github.com/azimul-kabir/actua/pull/887))
- No database schema, encryption, Merkle or sync-protocol changes
