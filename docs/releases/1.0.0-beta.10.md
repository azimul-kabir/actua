# Actua 1.0.0-beta.10

Beta.10 brings Actua's most useful budget information and transaction actions to the Android home screen.

## Added

- **Budget Snapshot widget:** shows Ready to Budget, Budgeted, and Balance for the current month.
- **Favourite Categories widget:** displays up to four chosen spending categories with their balances and progress.
- **Quick Transaction widget:** opens a new Expense, Income, or Transfer with the correct transaction type selected.
- **Account Balances widget:** displays up to four chosen open accounts and opens the selected account's transactions.
- **Launcher quick actions:** long-press the Actua app icon to add an Expense, Income, or Transfer, or open Search.

## Widget behavior

- Category and account widgets can be configured when added and reconfigured from supported Android launchers.
- Widget taps open the corresponding Actua screen rather than a generic start page.
- Amounts follow Actua's currency, decimal-place, and Hide balances preferences.
- Widgets use light or dark colors and Material You dynamic colors on supported Android versions.
- Data is read from the selected local budget, so existing snapshots remain available offline.
- Widgets refresh after local edits, successful synchronization, relevant display-setting changes, app foregrounding, and Android's periodic refresh.

## Development workflow

- Actua development now requires a GitHub issue before implementation and a linked pull request for every change.

## Upgrade and testing

- Continues using Actua's persistent release signing key and can upgrade recent beta installations in place.
- After installing, long-press an empty area of the Android home screen, select **Widgets**, find **Actua**, and add the widgets you want.
- Please test widget resizing, category/account reconfiguration, tap navigation, app-icon shortcuts, dark mode, and balance privacy on your launcher.

> **Beta safety notice:** Actua can write changes back to a synchronized Actual budget. Create and keep an independent Actual Budget backup before testing with an important budget.
