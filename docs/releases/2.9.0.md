# Actua 2.9.0

Actua 2.9.0 speaks six more languages: French, German, Italian, Japanese, Russian and Simplified Chinese. You can scan a
receipt onto a transaction you already entered, turn any transaction into a schedule, and see what's new the first time
you open an update. The Budget table view is denser and easier to read, with equal columns, fixed status colors and an
optional edge-to-edge look, and reports support more of Actual's saved options. Supporters get a custom accent color,
ten app icons and a widget style pack.

## Before you update

- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a new
  version with a real budget.
- **Budgets in yen, won or rial:** amounts were stored at the wrong scale before this release. Existing amounts are not
  rewritten; any you typed in Actua in these currencies need to be entered again, as Actual's own release asks.
- GitHub releases now ship one APK, `Actua-v2.9.0.apk`, which is the Google Play build. If you installed the Direct Full
  APK from GitHub, see Notes.

## Notes

- **One APK on GitHub.** `Actua-v2.9.0.apk` is the same build as the Google Play version. The Direct Full build is gone,
  and earlier GitHub installs update in place. Play and GitHub installs are still signed with different keys, so to move
  between them back up your budget, uninstall, install the other one and restore.
- **New languages.** Actua follows your phone's language, or pick one under Settings → Display → Language. Store listing
  text and What's new notes are translated too.
- **Use accent color** (formerly Color balances) is optional. With a red, orange or amber accent it keeps the standard
  status colors so a normal category never looks like a warning.
- **Supporter extras are cosmetic and optional.** Budgeting stays free for everyone.
