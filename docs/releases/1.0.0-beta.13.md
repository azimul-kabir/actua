# Actua 1.0.0-beta.13

This beta expands category automation support, adds regional display formatting,
and improves bottom navigation on compact and scaled Android layouts.

## Highlights

- **Multiple automations per category.** Edit supported target definitions
  together and control their priority order from the category automation editor.
- **Safe priority handling.** Actua evaluates supported automations in their
  stored order while leaving unknown and notes-managed definitions unchanged.
- **Goal-only targets.** Track a desired category balance without automatically
  assigning money during Auto-Assign or whole-budget template application.
- **Regional display controls.** Choose date and number formats under
  **More → Display** without changing stored dates or monetary values.
- **Responsive navigation labels.** Bottom navigation labels stay on one line
  and resize when narrow screens, display scaling, or font scaling reduce space.
- **Compact icon-only navigation.** Turning off bottom-navigation labels now
  reduces the bar to a 64 dp content area while retaining the Android system
  bottom inset, centered icons, full accessibility descriptions, and practical
  touch targets.

## Upgrade notes

Actua 1.0.0-beta.13 uses the same production application ID and persistent
release signing identity as recent beta releases, so it should install as a
normal in-place update over beta.12. Obtainium users who enabled prereleases
should receive the update after publication.

> [!CAUTION]
> Actua remains beta software and can write synchronized changes back to an
> Actual budget. Create an independent backup of an important Actual budget
> before testing, and confirm important changes have synchronized before
> uninstalling or resetting Actua.
