# Actua 2.2.1

Actua 2.2.1 is a bugfix release following 2.2.0. It fixes OpenID sign-in failing immediately when the browser opens, restores equal column widths in the Budget table stacked layout when goal icons are disabled, allows wide table amounts to scale down smoothly without premature wrapping, and simplifies the Budget display options sheet to keep all sections expanded.

## Before you update

- **Display options are always expanded.** In the Budget tab ⋮ menu > Display options, all sections are now shown expanded in a scrollable sheet without requiring taps on collapsible headers.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a new version with a real budget.

## Changed

- Budget display options now always shows all sections (Page, Each category row, Categories shown) expanded in a clean scrollable sheet ([#1321](https://github.com/azimul-kabir/actua/pull/1321))

## Fixed

### OpenID sign-in

- Fixed OpenID sign-in failing immediately with a closed listener when the browser opens, by keeping the loopback callback server alive across Connection screen recomposition ([#1320](https://github.com/azimul-kabir/actua/pull/1320))

### Budget table layout

- Fixed the Budget table stacked balance column keeping extra width when goal icons are turned off, restoring equal column proportions ([#1318](https://github.com/azimul-kabir/actua/pull/1318))
- Lowered the minimum scale floor from 75% to 60% and enabled auto-sizing within allocated columns so wide currency amounts scale down smoothly without prematurely wrapping into the stacked layout ([#1318](https://github.com/azimul-kabir/actua/pull/1318))

## Compatibility and safety

- The OpenID callback listener change affects only the local loopback server lifecycle on the Connection screen during sign-in; the listener is properly closed when navigating away from the screen or upon flow completion.
- The Budget table column weight and scaling adjustments are presentation-only Compose layout changes; stored budget amounts, calculations, and database structures are unchanged.
- The Display options sheet change is presentation-only.
- No database schema, Merkle tree, encryption or sync-protocol changes.

## Since 2.2.0

This release includes #1318 (table layout and column weights), #1320 (OpenID callback listener) and #1321 (always-expanded display options), plus the issues they close or reference (#1284, #1317 and #1319).
