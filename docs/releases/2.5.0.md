# Actua 2.5.0

Actua 2.5.0 adds receipt scanning, encrypted WebDAV backup and a set of everyday entry improvements. In the Google
Play version, and in a new `-full` APK on GitHub, you can photograph or pick a receipt and Actua suggests the payee,
date and total, offers the tax and items as split lines, and can keep the photo on your phone. You can now back up to
your own Nextcloud, ownCloud or NAS over WebDAV with the same client-side encryption as Google Drive. The amount
keypad gains Paste, Clear with Undo and a leading minus, a new transaction can start with the date of the last one,
the Bills calendar can be a tab, and a category's transactions can show a running total.

## Before you update

- **Two APKs on GitHub.** Each release now has `Actua-v<version>.apk`, the fully open-source build with no Google
  libraries (the one F-Droid verifies), and `Actua-v<version>-full.apk`, which adds receipt scanning and the Google
  Play purchase code. They use the same app ID and signing key, so you can switch between them without losing data.
  Obtainium lists both; set its APK filter to pick one (for example `-full`). The Google Play version is the full
  build.
- **Receipt scanning is a Google Play and `-full` feature.** It uses Google ML Kit's on-device text recognition with
  models bundled in the app, which makes that build larger. The photo is read on your phone and is never uploaded.
  Latin, Chinese, Japanese, Korean and Devanagari are read; Cyrillic, Arabic, Hebrew, Thai, Greek and Bangla may not
  be. Everything it suggests is shown for you to check before anything is saved.
- **A kept receipt photo stays on this phone.** It is never synced to Actual and never part of a backup or an
  export, so it is not on another phone and not after restoring a backup. If you choose a receipt photo folder, those
  photos are outside the app lock and any app that syncs that folder will copy them. Actua itself never uploads them.
- **WebDAV backup is new and has only been tested against an in-memory test server.** It has not yet been run
  against Nextcloud, ownCloud or a NAS (see [docs/WEBDAV_BACKUPS.md](../WEBDAV_BACKUPS.md)). Keep another backup,
  such as a local one or Google Drive, until you have restored from it once.
- **Keypad subtraction can now flip a transaction's type.** Pressing − before any number makes the first number
  negative, and a result below zero becomes the opposite of the transaction's type. For example `50 − 100` on a new
  expense is now an income of 50 instead of an expense of 50. The ± key still switches between expense and income.
- **A category's transaction list now includes splits** that have a line in that category.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.

## Added

### Receipts (Google Play and `-full` APK)

- Scan a receipt photo from a new transaction, or from the keypad's Scan button, to suggest the payee, date and
  total. Nothing is saved until you tap Save ([#1471](https://github.com/azimul-kabir/actua/pull/1471))
- Offer the receipt's tax and items as split lines. The tax is on by default and the items, the least reliable part
  of a scan, are off ([#1474](https://github.com/azimul-kabir/actua/pull/1474))
- Keep the receipt photo with the transaction, on this phone only, and open or remove it from the transaction
  ([#1476](https://github.com/azimul-kabir/actua/pull/1476))
- Choose a folder for kept receipt photos, for example on an SD card or in a folder a sync app mirrors, with a plain
  warning that it is outside the app lock ([#1477](https://github.com/azimul-kabir/actua/pull/1477))

### Backups

- Encrypted backup to a WebDAV server such as Nextcloud, ownCloud or a NAS, with manual backup, a list of backups and
  restore into the open budget ([#1454](https://github.com/azimul-kabir/actua/pull/1454),
  [#1455](https://github.com/azimul-kabir/actua/pull/1455))
- Automatic uploads of each backup to the WebDAV server, retried when they fail
  ([#1457](https://github.com/azimul-kabir/actua/pull/1457))
- Restore a backup from a WebDAV server on a fresh install, from the no-budget screen and Connection and Data
  ([#1459](https://github.com/azimul-kabir/actua/pull/1459))
- Ask for Nearby devices access before reaching a WebDAV server on the home network on Android 17 and later
  ([#1462](https://github.com/azimul-kabir/actua/pull/1462))

### Entering transactions

- Paste an amount from the clipboard in the amount keypad ([#1451](https://github.com/azimul-kabir/actua/pull/1451))
- Clear the keypad, with Undo right after ([#1453](https://github.com/azimul-kabir/actua/pull/1453))
- A leading minus makes the first number negative, so `−1 − 0.01` works, and a negative result flips the type
  ([#1469](https://github.com/azimul-kabir/actua/pull/1469))
- A setting to start a new transaction with the date of the last one you added, until you close the app
  ([#1468](https://github.com/azimul-kabir/actua/pull/1468))
- A new transaction no longer opens the account picker when you add it from inside an account, or the category
  picker when the payee already filled it in ([#1470](https://github.com/azimul-kabir/actua/pull/1470))

### Navigation and lists

- The Bills calendar can be added as a bottom bar tab, within the five-tab limit
  ([#1467](https://github.com/azimul-kabir/actua/pull/1467))
- A running total for a category's transactions when the list is filtered to that category, available from the list
  menu ([#1478](https://github.com/azimul-kabir/actua/pull/1478))

### Downloads

- GitHub releases include a full APK next to the open-source one
  ([#1473](https://github.com/azimul-kabir/actua/pull/1473))

## Fixed

## Compatibility and safety

- **Database and sync:** no schema, Merkle tree, encryption or sync-protocol changes. Receipt photos and the photo
  link are never written to the budget database or the message log, and are not in any archive.
- **Receipts:** text recognition runs on the phone with bundled models. A photo you take is a temporary cache file
  that is deleted once it has been read; only a copy you choose to keep is stored, as a compressed JPEG in Actua's
  private storage (or the folder you chose). Android backup and device transfer exclude that folder. `PRIVACY.md`
  describes all of this.
- **WebDAV:** backups are encrypted on the phone before upload; the server only receives ciphertext. HTTPS is
  required unless you allow plain HTTP after a warning; a self-signed certificate can be trusted by fingerprint.
  Credentials are stored with the Android Keystore and excluded from Android backup and transfer.
- **Keypad and lists:** the keypad changes affect only the add and edit transaction amount; the budget and account
  keypads are unchanged. The category running total is the total of the rows shown, not the category's budget
  balance, and is not an Actual behavior.
- **Releases:** the release workflow now also builds and signs the Play build as an APK. The open-source
  `Actua-v<version>.apk` is built exactly as before.
- **Testing:** this release was verified by Actua's automated tests, lint and the Android 9, 15 and 16 emulator
  runs. Receipt scanning, kept photos and the photo folder, WebDAV backup, and the new release workflow step were
  not run against a real receipt, a real WebDAV server, a physical device or a real release before this one; see
  `RELEASE_SMOKE_TEST.md` for the device checks.
