# Actua 1.8.1

Actua 1.8.1 fixes captured transactions and the Tasker plugin based on feedback on 1.8.0. It also
follows dark mode from the first frame, fits Budget table amounts on small screens, and adds an
option to show balances without pills.

## Before you update

- **Tasker amounts are read more leniently.** The action now takes the first number in the
  amount, so `Rs. 1,234.50` or `$10.69` work without cleaning them in Tasker first. With Type set to
  "From the amount's sign", `-%amount` turns a negative refund into money in. Type Debit or Credit
  still always decides the direction.
- **Captured payees keep their case.** Payees from bank notifications, shared text and Tasker are
  no longer title-cased, so `STARBUCKS 1234` stays as it is. Statement files (CSV, XLSX, PDF) are
  still title-cased, as in Actual. Rules and payee matching ignore case, as before.
- As always, let Actua finish syncing before you update, and keep an independent backup from
  Actual before using a new version with a real budget.

## Added

- A Budget display option to show balances as plain amounts instead of on pills ([#1091](https://github.com/azimul-kabir/actua/pull/1091))

## Fixed

### Captured transactions and Tasker

- Captured alerts from a card named "Credit" are no longer imported as income ([#1074](https://github.com/azimul-kabir/actua/pull/1074))
- Rejected captured transactions no longer come back in Review captured ([#1077](https://github.com/azimul-kabir/actua/pull/1077))
- A Tasker action whose amount variable wasn't set now says which variable was missing ([#1075](https://github.com/azimul-kabir/actua/pull/1075))
- The Tasker action reads the amount's number even with currency prefixes like "Rs." or a doubled minus sign ([#1081](https://github.com/azimul-kabir/actua/pull/1081))
- Captured, shared and Tasker transactions keep the payee's original case ([#1093](https://github.com/azimul-kabir/actua/pull/1093))

### Appearance and layout

- The splash screen follows the device's dark mode instead of always being white ([#1079](https://github.com/azimul-kabir/actua/pull/1079))
- Status and navigation bar icons follow the app's Light or Dark appearance instead of the device's ([#1086](https://github.com/azimul-kabir/actua/pull/1086))
- Budget table view amounts no longer get cut off in the overview and group totals on narrow screens or large text ([#1087](https://github.com/azimul-kabir/actua/pull/1087))
- Budget table view category amounts stay on one line instead of being cut off at large text sizes ([#1089](https://github.com/azimul-kabir/actua/pull/1089))

## Compatibility and safety

- Captured, shared and Tasker transactions are still imported only from the review page or a
  notification's Import action, through the same atomic CRDT import path as statement files.
  Rejecting a capture only removes it from the device-local queue.
- Keeping the payee's case changes only the text of new payees and `imported_payee` for
  Android-only sources; file imports still match Actual's title-casing.
- Tasker amounts are still converted to integer cents; a broadcast with no number is rejected
  with a reason and nothing is queued.
- The balance pill option, splash and system bar changes are presentation only.
- No database schema, encryption, Merkle or sync-protocol changes.
