# Actua 2.5.2

Actua 2.5.2 fixes the `#tag` suggestions in Add transaction, which got stuck on the first few tags. It also redesigns
the Scan receipt chooser and moves Paste on the amount keypad.

## Before you update

- Receipt scanning is in the Google Play version and the `-full` APK only; this release does not change that.
- As always, let Actua finish syncing before you update, and keep an independent backup from Actual before using a
  new version with a real budget.

## Changed

- Redesigned the Scan receipt chooser, and moved Paste next to Done on the amount keypad in place of its Scan link
  ([#1497](https://github.com/azimul-kabir/actua/pull/1497))

## Fixed

- Fixed the #tag suggestions in Add transaction getting stuck on the first tags; they are now a scrollable row
  ([#1498](https://github.com/azimul-kabir/actua/pull/1498))
