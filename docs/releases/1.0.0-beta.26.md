# Actua 1.0.0-beta.26

Beta 26 reworks the To Budget summary into a single, flatter sheet and enables
R8 code and resource shrinking for release builds, cutting release APK size.

## Changed

- Reworked the To Budget summary into a single flat sheet: tapping the Ready/To Budget amount (Plan or classic view) now shows "Move to Category" and "Hold for Next Month" as direct tiles instead of behind a "⋮" overflow menu with a nested popup; a "Reset Hold" tile appears directly alongside once an amount is held
- Enabled R8 code shrinking and resource shrinking for release builds to reduce APK size; the app already relied on consumer ProGuard rules shipped by pdfbox-android, WorkManager, and Compose, so no project-specific keep rules were needed

## Fixed

- Fixed the "Syncing budget… Showing local data." banner appearing on every local edit (adding/editing transactions, budgeting a category, toggling cleared, etc.); it now only appears for app-open and background syncs, which can bring in changes the screen doesn't have yet, not for the upload triggered by an edit you just made

## Compatibility and safety

- The To Budget summary rework is UI-only: no changes to the underlying budget buffer data layer, CRDT sync semantics, or current/next-month amount math introduced in beta.25
- Enabling R8 does not change any data layer or sync behavior; it only shrinks and obfuscates the release build's code and unused resources
